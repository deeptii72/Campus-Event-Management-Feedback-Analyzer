# Campus Event Management & Feedback Analyzer

## 📌 Project Overview
The **Campus Event Management & Feedback Analyzer** is an integrated platform designed to streamline the planning, organization, and execution of campus events while automatically analyzing attendee feedback. It helps organizers manage event schedules, registrations, and gather data-driven insights from student responses to improve future events.

## 🚀 Features
* Create, manage, and update campus event schedules and details.
* Collect and manage participant registrations and attendance.
* Integrated feedback system to gather ratings and reviews from attendees.
* Automated feedback analysis to generate sentiment reports and insights.
* User-friendly interface for students and event coordinators.
